# AI 安全与成本

## 调用前

- 先执行确定性解析、验证和脱敏；
- 只发送完成任务必需的结构化摘要；
- 固定 Lab 允许的模型能力和最大输出；
- 给请求设置稳定 Schema、超时和幂等标识；
- 将用户内容作为不可信数据，不允许其修改系统规则。

## 调用后

- 验证 JSON Schema；
- 检查是否重新输出秘密模式；
- 明确标记 AI 内容；
- 保留确定性结果，不让 AI 覆盖事实；
- 无效响应最多有限重试一次，然后降级。

## 成本控制

至少限制：单请求输入、单请求输出、IP/匿名会话频率、Lab 日预算、全站日预算、最大并发和 Provider 超时。

预算耗尽时，样例模式和确定性核心继续可用。日志只记录 Lab ID、模型代号、耗时、Token 数、状态和粗粒度错误码。

Token Forge 的固定数值、先预留后结算、匿名用户键、熔断和持久化要求见
[AI 流量与成本策略](./token-forge-ai-traffic-policy.md)。成本预留必须覆盖一次 Gateway
请求内的全部 Provider 尝试；只有服务端汇总的可信实际 Token 与微美元成本可以触发退款，
失败、进程中断或预留过期均按全额计费。
