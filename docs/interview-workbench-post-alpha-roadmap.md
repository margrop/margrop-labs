# AI 面试工作台 Post-Alpha 路线图

## 当前结论

截至 2026-07-29，P5-001 至 P5-009 已完成，工作台达到**合成 Alpha GO**。当前页面只接受
仓库内完全合成样例；真实简历、真实岗位说明、真实面试记录和招聘用途仍为 **NO-GO**。

后续工作必须严格按 P5-010 至 P5-015 顺序执行。只有当前任务完成并满足验收门槛后，才能
启动下一项。近期唯一允许启动的任务是 **P5-010**。

## 不变边界

- 合成样例模式始终无需 AI、无需登录，并保留为默认回退路径；
- 不新增登录、支付、候选人数据库、跨会话画像或自动录用/淘汰能力；
- 原始敏感文本不得进入 URL、Analytics、错误追踪、服务日志、分享卡或 AI 请求；
- unknown 不得转换为负分，受保护属性不得参与解析、匹配、提问或结论；
- AI 只处理操作所需的最小脱敏结构化投影，输出验证失败时必须降级；
- 继续复用既有 AI Provider、模型、Secret、端口、策略外壳和 Analytics binding；
- 真实输入能力涉及敏感数据和公共合同，必须先由 P5-010 ADR 明确批准。

## 阶段 A：决策与合同

### P5-010 — 真实输入边界 ADR 与威胁模型（已完成）

**性质：规划与决策，不实现真实输入。**

产物：

- 一份 ADR，决定是否支持粘贴、文件导入或两者，以及首期允许的格式；
- 输入大小、字符编码、解析超时、文件数量和失败关闭规则；
- 浏览器会话生命周期、刷新/关闭行为、显式清除和内存释放语义；
- 原文、本地结构化数据、AI 最小投影和导出内容的数据流与信任边界图；
- XSS、公式/文档注入、提示注入、压缩炸弹、路径穿越和敏感字段泄漏威胁模型；
- 导出前确认、受保护属性处理、测试语料来源和真实数据 Beta 门槛；
- 新依赖评估；如标准 Web API 足够，则明确不新增依赖。

验收：

- 明确首期支持与拒绝的输入形式，不保留“实现时再决定”的安全关键项；
- 每类敏感数据都有收集、处理、发送、导出和删除规则；
- 明确禁止服务端原文解析、持久化和请求正文日志；
- 仓库所有者批准 ADR 后，P5-011 才能解锁。

## 阶段 B：本地确定性接入

### P5-011 — 本地简历与岗位说明接入内核（已完成）

产物：

- 版本化 Import/Input Schema、失败行为和合成 fixtures；
- 浏览器本地解析、规范化、大小限制、类型识别和安全字符处理；
- Resume/JD v1 的确定性映射，不调用网络、AI 或存储；
- 有效/无效输入、XSS、注入、超限和五类敏感 sink 自动测试。

验收：

- 解析逻辑与 UI、网络、AI Provider 分离；
- 原文只存在于当前浏览器会话，刷新/清除行为符合 P5-010；
- 不支持的格式、损坏内容和超限输入均给出中文可恢复错误；
- 合成样例模式保持不变并继续通过现有回归。

### P5-012 — 真实输入本地工作台 UI

产物：

- 经 P5-010 批准的粘贴/导入入口、验证预览、错误恢复和显式清除；
- 原文与规则结果、输入证据、AI 解释、未知项的清晰分区；
- 导出字段预览与二次确认；
- 移动端、键盘、焦点、reduced motion 和基础无障碍回归。

验收：

- 无需登录、AI 或持久化即可完成真实输入的本地确定性流程；
- 页面不把敏感内容写入 URL、DOM 属性、Analytics 或错误报告；
- 清除后不能从工作台状态恢复原文；
- AI 不可用时仍能继续规则化流程和安全导出。

## 阶段 C：AI 最小边界

### P5-013 — 真实输入的 AI 最小投影

产物：

- 三项操作各自的版本化 allowlist 投影、脱敏和请求 Schema；
- 真实输入到 requirement/evidence ID 的最小结构化映射；
- 继续复用现有服务端运行时、模型策略、预算、限流、超时和熔断；
- 超时、限流、Provider 失败、无效 JSON、Schema 无效和降级测试。

验收：

- 浏览器不能发送原始简历/JD、受保护属性、Provider 控制字段或 Secret；
- 服务端不记录请求正文，只保留已批准的元数据；
- AI 输出必须通过版本化 Schema 与引用完整性验证后才能渲染；
- 任一 AI 故障不阻断本地确定性流程。

## 阶段 D：可靠性与 Beta 评审

### P5-014 — 隐私、公平性与对抗可靠性扩展

产物：

- 更大的合成岗位族、简历形态、语言与缺失信息语料；
- 受保护属性、代理变量、提示注入、恶意文档内容和超限输入矩阵；
- URL、日志、Analytics、导出和 AI 请求五类 sink 回归；
- 人工确认、unknown、反证和自动决策失败关闭回归。

验收：

- 所有允许输入类型均覆盖有效、无效、敏感和对抗样例；
- 不存在原文泄漏、受保护属性参与判断或自动录用/淘汰路径；
- 规则结果与 AI 建议的差异可见且可追溯；
- 可靠性报告明确区分技术安全证据与招聘质量证据。

### P5-015 — Beta 出口评审

产物：

- Preview 部署与完整验证记录；
- 隐私、公平性、可靠性、成本、可访问性和已知限制报告；
- 真实候选人数据使用的 GO/NO-GO 决策和必要的后续观察计划；
- Production 部署建议，但不自动执行 Production 发布。

验收：

- 根目录 `npm run validate` 与 Preview 关键路径全部通过；
- 明确“工具技术边界通过”不等于“招聘质量已验证”；
- 缺少真实场景质量、公平性或运营证据时，真实招聘用途保持 NO-GO；
- 只有评审明确 GO 后，才能另建 Production 或真实观察任务。

## 依赖顺序

```text
P5-010 ADR 与威胁模型
  → P5-011 本地确定性接入内核
  → P5-012 本地工作台 UI
  → P5-013 AI 最小投影
  → P5-014 隐私/公平/对抗可靠性
  → P5-015 Beta 出口评审
```

不得并行实现 P5-011 至 P5-015，也不得用实现代码替代 P5-010 的决策评审。

## 当前下一步

P5-010 与 P5-011 已完成，当前只启动 **P5-012**：把纯文本粘贴、验证预览、显式清除和
合成恢复接入工作台 UI。文件导入、持久化和服务端原文解析仍不在范围内。
