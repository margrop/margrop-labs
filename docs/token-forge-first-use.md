# Token Forge 首次使用与移动端闭环

P1-012 在不改变 Input / Plan / Export / Agent Package v1 合同的前提下，为
[`/token-forge/`](https://lab.margrop.net/token-forge/) 增加无需文档即可完成的三步路径：

1. 选择三档样例之一，或修改表单；
2. 生成并检查确定性模板；
3. 复制或下载完整计划、Issue 草稿或 Coding Agent 执行包。

样例按钮直接生成模板，不会暗中调用 AI。用户仍可在表单中显式选择 AI 增强。

## 三档样例

| ID                |  Token | 目标体验               | 仓库边界                     |
| ----------------- | -----: | ---------------------- | ---------------------------- |
| `quick-local`     |  6,000 | 一个 S 级合同加固任务  | 完全本地，不读取仓库         |
| `standard-public` | 24,000 | 一个 M 级完整功能切片  | 只读 `margrop-labs` 公开仓库 |
| `deep-local`      | 40,000 | 三阶段依赖安全离线 MVP | 完全本地，不读取仓库         |

三个样例都无需登录和 AI。`standard-public` 只使用既有 P1-003 有界公开读取；GitHub
超时、限流、不可用或摘要校验失败时，页面显示降级原因并继续提供本地模板与三种导出。

样例目录是只读常量；每次载入都会返回新的表单副本，页面修改不能污染下一次运行。样例目标
只包含公开合成需求，不含账号、私有仓库、文件正文或凭据。

## 渐进状态

页面始终显示“选择 → 生成 → 导出”三步状态，不用颜色单独表达进度：

- 初始空状态说明如何从样例或表单开始；
- 生成状态说明公开仓库或 AI 失败会保留模板；
- 成功后只把键盘焦点移动到结果标题一次，后续本地编辑不会抢焦点；
- 表单错误保留原输入，同时提供“回到输入修改”和“恢复 6K 安全样例”；
- 仓库或 AI 降级仍显示完整结果、规则证据与可用导出，不制造不可操作的错误页。

## 结果导航

结果区提供四个原生锚点：

- `#forge-tasks`：任务计划；
- `#forge-editing`：本地编辑；
- `#forge-evidence`：规则证据与降级说明；
- `#forge-exports`：复制或下载。

宽屏显示四列，600px 以下改为两列；链接保持至少 44px 高。结果段落使用
`scroll-margin-top`，避免定位后被导航遮挡。`prefers-reduced-motion: reduce` 继续关闭
平滑滚动；程序化结果定位不使用动画。

## 隐私与成本

P1-012 不增加 Schema、依赖、存储、Analytics 字段或模型调用。样例选择、引导状态和导航
只存在于当前页面。24K 公开仓库样例复用既有固定 Origin、无鉴权、大小/文件数/超时上限；
其他两个样例完全本地。

## 验证

- 单元测试证明三档预算、公开仓库样例、模板与三种导出保持一致；
- 每次载入返回独立表单副本；
- 静态产物检查三步引导、错误恢复文案、结果锚点、键盘控件和响应式 CSS；
- 根目录 `npm run validate` 继续覆盖 320px CSS、44px 触控目标、forced colors 与
  reduced motion 合同。

P1-013 才会加入真实浏览器关键路径和至少 30 个端到端基准；P1-012 不把静态合同冒充为
完整跨浏览器基准。
