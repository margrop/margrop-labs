# AI 面试工作台本地文本 UI v1

P5-012 把 P5-011 的确定性解析器接入公开工作台。

## 用户路径

1. 在“简历文本”和“岗位 JD 文本”中粘贴纯文本；
2. 点击“生成本地工作台”；
3. 查看岗位、要求数量、技能信号和保守解析提醒；
4. 继续使用岗位匹配、面试计划、记录与安全导出；
5. 点击“清除真实输入”或“恢复样例”删除原文并返回完全合成流程。

## 状态与隐私

- textarea 是唯一真实输入入口，没有文件选择器；
- 原文只保存在组件状态，不写入 URL、Storage API、Cookie 或 Analytics；
- 失败提示使用固定中文消息，不回显输入；
- 清除会同时删除原文、派生 run、AI 状态和解析摘要；
- 合成模式始终可用，不要求登录、网络或 AI。

## AI 边界

P5-013 已启用真实输入场景的三个既有 AI 端点。按钮只发送操作专属 allowlist 投影；原文、
完整职责/经历段落、联系方式、受保护属性和浏览器控制字段不进入请求。
