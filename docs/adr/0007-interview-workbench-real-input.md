# ADR-0007：AI 面试工作台真实文本输入边界

- 状态：Accepted
- 日期：2026-07-29
- 决策者：仓库所有者
- 关联任务：P5-010

## 背景

AI 面试工作台已完成只接受完全合成样例的 Alpha。下一阶段需要让用户录入自己的简历和岗位
JD，同时保持无需登录、本地优先、无候选人数据库、无自动招聘决策和最小 AI 投影边界。

真实简历和岗位说明可能包含个人身份信息、受保护属性、公司内部信息、提示注入文本和恶意
HTML。直接把原文发送到 Worker、模型或日志不符合现有产品合同。

## 决策

### 首期输入形式

首期只支持两个纯文本粘贴入口：

1. 简历文本；
2. 岗位 JD 文本。

不支持 PDF、DOC、DOCX、图片、压缩包、URL 抓取、剪贴板自动读取或拖拽文件。文件解析需要
独立 ADR 和依赖、安全、许可证评审，不在 P5-011 至 P5-013 范围内。

### 大小与解析限制

- 每个文本输入按 UTF-8 计算最多 32 KiB；
- 每项至少 20 个非空白字符；
- 拒绝 NUL、不可解码文本和纯标记内容；
- 解析为同步、确定性、本地操作，不调用网络、AI、Storage API 或 Worker；
- 输入只作为文本处理，不解析或执行 HTML、Markdown、脚本、公式、链接和提示词指令；
- 错误消息只报告类型和限制，不回显原文。

### 生命周期与删除

- 原文只保存在当前 Preact Island 的内存状态中；
- 不使用 localStorage、sessionStorage、IndexedDB、Cache API、Cookie 或 URL；
- 刷新、关闭标签页或点击“清除真实输入”即丢弃原文和所有派生状态；
- 清除后恢复到仓库内合成样例，不提供撤销或跨会话恢复；
- 页面离开时不发送 beacon，也不把原文写入错误追踪或 Analytics。

### 本地确定性投影

本地解析器只生成现有 Resume/JD/Requirement/Evidence v1 合同：

- 标题、职责、经历、技能和要求由固定分段、列表和关键词规则提取；
- 无法确认的字段使用明确 unknown 描述，不伪造候选人经历；
- 匹配只依据要求与简历文本的可解释关键词交集；
- 缺少交集输出 unknown，不输出负分；
- 受保护属性和招聘歧视性要求会被拒绝，不能进入匹配、问题或 AI 投影。

### AI 边界

- AI 按钮继续由用户显式触发；录入和本地匹配本身不调用 AI；
- 继续使用现有三个同源端点、Provider、模型、Secret、预算、限流、超时和熔断；
- 请求只包含版本化 allowlist 结构化投影、引用 ID、类别、优先级和脱敏短标签；
- 不发送简历/JD 原文、完整段落、联系方式、受保护属性、Prompt 指令或浏览器控制字段；
- 服务端不记录请求正文；无效响应或任一运行时故障必须降级为本地结果。

### 导出

- 默认安全摘要继续排除简历、JD、问题、记录正文和个人标识；
- 用户必须主动点击导出；
- 导出区域在按钮旁明确列出被排除字段；
- 本阶段不提供“导出原始简历/JD”功能。

## 后果

- 用户可以立即粘贴真实文本并获得本地确定性工作流；
- 纯文本范围降低了解析器供应链、文档宏、压缩炸弹和路径穿越风险；
- 格式复杂的简历可能只得到保守的 unknown 或部分匹配，需要用户调整文本结构；
- 本决策证明的是数据边界和技术可控性，不证明招聘质量或公平性已通过真实场景验证。

## 拒绝方案

### 首期直接支持 PDF/DOCX

拒绝。需要额外解析依赖、复杂文档攻击面和许可证审查，且不是建立可验收录入入口的必要条件。

### 把原文发送给模型完成解析

拒绝。确定性解析和安全判断不能交给 AI，原文也不得跨越浏览器边界。

### 使用浏览器持久化保存草稿

拒绝。当前没有登录、加密密钥管理、保留期限或删除审计合同，默认持久化会扩大隐私风险。
