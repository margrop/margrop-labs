# Token Forge 正式页面、仓库证据与事件合同

P1-006 把 P1-002 的确定性模板和 P1-005 的本地导出接到
[`/token-forge/`](https://lab.margrop.net/token-forge/)；P1-007 在同一页面加入可选的
P1-003 公开 GitHub 仓库摘要；P1-008 再加入显式选择的服务端 AI 增强。

## 用户路径

1. 静态 HTML 说明无需登录、仓库可选且只读公开数据、AI 仅显式触发、不保存输入；
2. 用户输入 Token 预算、到期天数、可投入工时、技术栈、可公开目标和可选仓库 URL，或载入
   不含仓库地址的合成样例；
3. 浏览器先做数值约束、允许字段映射、PII 脱敏和 Secret 拒绝；
4. “仅生成模板”直接生成 `mode: "template"` 的确定性计划和本地导出；
5. 仓库 URL 留空时不发网络请求；URL 有效时，P1-003 只向固定 GitHub API Origin 读取受限
   的公开元数据、目录树和文本样本；
6. 成功时页面只保留固定技术标签、覆盖计数和代码生成的未知项；路径与文件正文不会进入页面
   结果；
7. “AI 增强生成”只发送 allowlist 目标、约束与脱敏后的最多 4 个无路径公开片段；浏览器
   不含 API Key、模型或系统指令；
8. AI 候选计划重新通过 Schema、依赖、Token、工时、脱敏、生产写入和仓库回显校验；成功
   后按最终计划重建两种导出；
9. 无效 URL、私有/不存在仓库、限流、超时、网络失败或无效响应只让对应证据降级，已经验证
   的模板计划和导出继续可用；
10. 用户复制或下载产物，是否提交给 Coding Agent 或 GitHub 由用户决定。

修改任一表单字段后旧结果立即失效。异步仓库请求带页面运行版本：过期请求即使稍后返回，也
不能覆盖新表单的状态。

## 表单边界

| 字段       | 页面约束                                                              |
| ---------- | --------------------------------------------------------------------- |
| Token 预算 | 2,000–60,000 的整数                                                   |
| 到期时间   | 1–30 天的整数                                                         |
| 可投入时间 | 1–80 小时，步长 0.5 小时                                              |
| 技术栈     | 1–8 项，逗号、中文逗号、分号或换行分隔                                |
| 公开仓库   | 可选；最多 200 字符，只接受规范的 `https://github.com/{owner}/{repo}` |
| 目标       | 10–500 字符                                                           |

目标和技术栈是不可信自由文本。邮箱、IP 等 PII 在进入计划前脱敏；Token、Cookie 和
Authorization 等 Secret 直接拒绝，错误消息不回显原值。

仓库 URL 先由固定解析器规范化，不经过自由文本域名脱敏。地址无效时，页面会删除无效地址后
生成模板结果，并显示稳定的仓库降级原因；不会把原地址写入错误消息。

## 仓库状态与安全投影

页面只公开三种仓库状态：

| 状态            | 页面行为                                                 |
| --------------- | -------------------------------------------------------- |
| `not-requested` | 不请求网络，显示“未提供 · 未读取”                        |
| `summarized`    | 显示目录项、读取、忽略、截断和未知计数，以及固定技术标签 |
| `fallback`      | 显示稳定失败类别，保留模板计划和两种导出                 |

“忽略”由疑似秘密路径/内容、二进制或生成文件、过大文件、读取失败和采样上限计数相加。
“截断”是目录树截断标记的 `0` 或 `1`。页面还显示各跳过类别，避免把受限样本误认为完整
仓库审计。

原始摘要只在当前标签页内短暂存在。页面投影明确丢弃：

- 仓库 owner、name、默认分支和原始 URL；
- 文件路径、大小明细和 `untrusted_text` 正文；
- 适配器原始未知项与原始错误消息。

技术标签只允许 TypeScript、Astro、Node.js、Python、Go、JVM、Rust 和 Docker 固定枚举；
未知项由覆盖计数重新生成。仓库内容不会进入模板任务、Analytics、站点 URL、日志或存储。
只有用户选择 AI 增强时，脱敏、截断且移除路径的公开片段才会短暂进入模型请求；原始摘要
仍不会进入 Markdown、Issue 草稿或策略快照。

网络边界继续由 [P1-003 适配器](./github-public-repository-adapter.md) 强制：固定
`https://api.github.com`、无 `Authorization`、禁止重定向、最多 8 个文件、单文件
32 KiB、总计 128 KiB、目录树 2,000 项、单次请求超时 5 秒，且只对 5xx 重试一次。

## 最小事件合同

事件使用 [`token-forge-event-v1.schema.json`](../schemas/token-forge-event-v1.schema.json)，
只允许以下五个字段：

- `schema_version`：固定 `1.0`；
- `event_name`：`lab_open`、`run_success`、`run_failure`、`export`、`blog_click` 或
  `github_click`；
- `lab_id`：固定 `token-forge`；
- `lab_version`：固定 `1.0`；
- `device_category`：`mobile`、`tablet`、`desktop` 或 `unknown`。

未知字段在事件边界丢弃。表单值、目标、仓库 URL、仓库覆盖、计划、导出正文、错误正文、
输入长度和高精度设备数据都不属于事件。仓库读取降级但模板成功时记为 `run_success`，因为
用户仍取得完整本地产物；只有表单或本地合同失败才是 `run_failure`。

P4-003 完成前，默认事件接收器是空实现：不发网络请求、不写存储、不打印日志。统计接入
失败也不得中断生成或导出流程。

## AI 状态与隐私

页面只公开三种 AI 状态：

| 状态                | 页面行为                                 |
| ------------------- | ---------------------------------------- |
| `not-requested`     | 完全使用本地模板，不向模型发送目标或摘要 |
| `ai-assisted`       | 显示最终验证计划、总 usage 与尝试次数    |
| `template-fallback` | 丢弃候选输出，显示模板和稳定降级状态     |

服务端固定主模型、顺序回退模型、端点、指令、每模型 22,000 输入、2,000 输出、共享
45 秒和 1 次 Gateway 尝试。API Key、匿名用户键、原始 IP、上游错误正文和无效模型正文
不会返回页面。服务端与浏览器都不记录目标、仓库片段或计划正文。

## 静态与可访问性

- 标题、主标题、隐私合同和表单由 Astro 预渲染，禁用 JavaScript 时仍可索引和理解；
- Preact 工作台使用 `client:visible`，不抢占首屏加载；
- 控件使用原生 `label`、`input`、`textarea` 和 `button`，提示通过
  `aria-describedby` 关联；
- 加载时表单使用 `aria-busy`，提交按钮禁用并显示文字状态；
- 成功、提示、降级和错误同时使用文字、符号与 ARIA 状态，不仅依赖颜色；
- 触控目标不小于 44px，字段、任务、覆盖计数和导出卡在 800px/600px 断点重排到单列；
- reduced-motion、forced-colors 和键盘焦点沿用站点基线。

构建后的首页与正式页面由静态合同脚本共同验收。
